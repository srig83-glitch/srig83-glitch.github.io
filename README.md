# Srividya Govindaraj — Developer Portfolio

Static portfolio prepared for GitHub Pages. Includes redacted authentic application images and a clearly labeled illustrative Timesheet & Expense preview.

## Publish

Upload the contents of this folder to the root of a GitHub repository. In Settings → Pages, choose Deploy from a branch, then main and / (root), and Save.

No build command, package installation, server, secrets or environment variables are required. The site entry is index.html and image paths are relative, so the site works under a repository subpath.

Only redacted assets are included. Original screenshots, résumé, presentations and deployment credentials are excluded.

GitHub documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
